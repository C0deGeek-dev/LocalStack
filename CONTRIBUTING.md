# Contributing

Thanks for your interest in LocalStack, part of the [LocalX](https://c0degeek-dev.github.io/LocalStack/) stack.

## Ground rules

- Keep changes scoped and focused; one concern per pull request.
- Match the surrounding code style and naming.
- Update the relevant docs when you change behavior or configuration.

## Building and testing

Static GitHub Pages site. Preview locally, then let the Pages deploy workflow and the link/copy check (`.github/workflows/links.yml`) validate your change.

## Pull requests

- Describe what changed and why, and link any related issue.
- Note how you tested the change.
- Expect review before merge.

## Reporting security issues

Do not open a public issue for a vulnerability. See [SECURITY.md](SECURITY.md).
