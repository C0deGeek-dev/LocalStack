# Security Policy

## Supported Versions

This repository is the LocalX landing site. It ships no runtime code; report
issues in the relevant component repository.

## Reporting security issues

Report a vulnerability privately through GitHub's **private vulnerability
reporting**: open the repository's **Security** tab and choose **Report a
vulnerability** (this opens a private advisory visible only to the maintainers).
Do not open a public issue and do not disclose a vulnerability publicly before a
fix is available.

If private reporting is unavailable, contact the repository owner privately
through their GitHub profile rather than filing a public issue.

## Security scope

Security-sensitive areas of LocalStack: the published landing site only (no runtime code).
