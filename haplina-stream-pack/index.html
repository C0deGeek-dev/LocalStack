Local streaming tools for OBS

One stream pack. Fewer moving parts.

Haplina Stream Pack is a local companion and overlay toolkit for OBS Studio. It combines themed scenes, alerts, on-stream controls and streaming-service integrations in a package that runs on the streamer's own PC.

What it does

Built around the streamer's own OBS setup.

Haplina Stream Pack provides browser-source overlays, scene assets, stream alerts, local controls and integrations for services a streamer chooses to connect. The application is designed to run locally rather than requiring a Haplina-hosted account or cloud dashboard.

OBS overlays & controls

Themed stream scenes, companion animations, alerts and controls intended for use as OBS Browser Sources.

Streaming integrations

Connect supported streaming services so the local interface can display and act on stream and chat information.

Local configuration

Settings and connection information are kept on the streamer's computer so the pack can reconnect between sessions.

User-controlled access

External-service access is initiated by the user and can be disconnected or revoked when it is no longer wanted.

Google / YouTube access

Why Haplina asks to connect to YouTube.

When a user enables the YouTube integration, Haplina Stream Pack uses Google's OAuth authorization flow to access only the YouTube functionality required for the features the user has chosen. Depending on the enabled feature and granted scope, this can include identifying the user's YouTube channel, finding the user's live broadcast, reading live-chat messages and metadata, and sending a chat message or carrying out a supported chat or broadcast action when the user explicitly requests it.

Haplina does not need access to Gmail, Google Drive, contacts, or unrelated Google account data.

Google/YouTube data is used to provide the streaming feature the user selected. Haplina's handling of information received from Google APIs is subject to the Google API Services User Data Policy and its Limited Use requirements.

Full details about access, local storage, sharing, retention, revocation and deletion are in the Haplina Stream Pack Privacy Policy.
